# Site Pessoal - David Dias

Este é um projeto de site pessoal desenvolvido com HTML e CSS puros, com o objetivo de apresentar informações sobre mim, minha formação acadêmica, projetos desenvolvidos e formas de contato. O site é simples, responsivo e pode ser utilizado como portfólio online.

## Tecnologias Utilizadas

- **HTML5**: Estruturação do conteúdo das páginas.
- **CSS3**: Estilização e layout responsivo.
- (Sem uso de frameworks ou bibliotecas externas)

## Páginas do Projeto

- `index.html` → Página inicial com informações **sobre mim**.
- `formacao.html` → Descreve minha **formação acadêmica** e competências.
- `portfolio.html` → Lista **projetos desenvolvidos**, com links para visualização.
- `contato.html` → Contém minhas **informações de contato** e um formulário simples.
- `style.css` → Arquivo principal de **estilos CSS**, compartilhado entre todas as páginas.
- `icon.png` → Imagem de perfil usada na página inicial.
- `framework.png` → Imagem criada como base para iniciar o projeto.

## Objetivo do projeto

- Praticar estruturação com HTML5.

- Criar estilos reutilizáveis com CSS3.

- Montar um portfólio pessoal simples e funcional.

- Servir como base futura para integração com JavaScript ou frameworks como React.
